🎲 1in8b Class Code Finder

In 1in8b.life's classroom mode, a class code pins the entire birth: same day + same code = the same baby — same country, same sex, same everything. This scans all 10,000 codes for any date, so you can pick the one that births you where you want.

How the trick works (and how to use a code)

The trick

The whole birth lottery is client-side. When you start a classroom life, the game seeds its RNG with:

setRng(seedRng('1in8b-class:' + CODE + ':' + YYYY + '-' + M + '-' + D))

The seed string is just the code and your browser's local date (month/day not zero-padded, e.g. 2026-7-4). seedRng hashes that string (FNV-style → mulberry32, a tiny seeded PRNG) — so the "random" birth is fully computable in advance:

  • draw 1 — country, weighted by annual births (India ≈ 17.6%, Hong Kong ≈ 0.03%)
  • draw 2 — sex (chance(srb): China .528 / India .519 / elsewhere .512 → male)

Same day + same code ⇒ same draws ⇒ the same baby. So you enumerate all 10,000 codes offline and pick.

Use a code

  1. Open 1in8b.life/en/?edu=1 (classroom mode).
  2. Choose the class-code option and enter a code from this page for today's date.
  3. Check the birth certificate — country and sex should match the chip you picked.

Limitations: one code works for one calendar day only (your local midnight flips it), and that life must run to the end before you can class-code again. Small countries get ~0–4 codes a day — some days have none. This page predicts country + sex; name, family and city are also fixed by the code but need deeper draws to compute.

Verify it yourself — paste this in the game's DevTools console

It calls the site's own seedRng and COUNTRIES, so there is zero port-drift risk. The site's CSP does not block DevTools console evaluation.

(() => {
  const DATE = '2026-10-21';           // local date, YYYY-M-D
  const WANT = 'HKG';                  // any ISO3 id
  const srb = id => id === 'CHN' ? 0.528 : id === 'IND' ? 0.519 : 0.512;
  const total = COUNTRIES.reduce((s, c) => s + Math.max(0, c.b), 0);
  const hits = []; let ind = 0;
  for (let i = 0; i < 10000; i++) {
    const code = String(i).padStart(4, '0');
    const rng = seedRng('1in8b-class:' + code + ':' + DATE);
    const r = rng();                                   // draw 1: country
    let x = r * total, pick = null;
    for (const c of COUNTRIES) { x -= Math.max(0, c.b); if (x <= 0) { pick = c; break; } }
    if (pick.id === 'IND') ind++;
    if (pick.id === WANT) hits.push(code + '(' + (rng() < srb(pick.id) ? 'M' : 'F') + ')');  // draw 2: sex
  }
  console.log('sanity IND', (ind / 100).toFixed(1) + '% (want 17–19)');
  console.log(WANT, DATE, hits.length ? hits.join(' ') : 'none today');
})();
